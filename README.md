# CivikSene-Ai
CivicSense AI is an intelligent complaint classification system that uses NLP to categorize urban issues, assign priority levels, and streamline resolution workflows through a FastAPI backend and interactive dashboard.


## 📌 Features
- 🧠 NLP-based complaint classification
- ⚡ Automatic priority detection (High / Normal)
- 📦 REST API using FastAPI
- 🗄️ PostgreSQL database integration
- 📊 Dashboard (Streamlit)
- 📧 Email alerts for urgent issues

## 🛠️ Tech Stack
- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Streamlit
